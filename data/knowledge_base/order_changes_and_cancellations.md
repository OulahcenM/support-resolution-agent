# Order Changes & Cancellations — Lumen & Co.

## Cancelling an order
Orders can be cancelled free of charge while their status is **pending** or **processing**. Once an order has shipped, it can no longer be cancelled; please request a return after delivery instead.

## Changing an order
Items, quantities, and the shipping address can be changed only before the order ships. Contact support as soon as possible — warehouse processing usually starts within a few hours.

## Cancellation refunds
Cancelled orders are refunded in full to the original payment method within 5–10 business days.
